# Translator Program

- Translate **Source Code** to **Object Code**
- 3 types of Translator Program
  - Assembler
  - Compiler
  - Interpreter

## Compiler

- Total program translate at a time and create a executable file and then execute the file
- need to compile only one time
- fast

## Interpreter

- Line by line translate then execute
- need to compile again and again
- slow

## Assembler

- Assembly (Pneumonic Code) Language to Machine Language
